REBOOT показывает, на что уходит время за компьютером, помогает задавать мягкие ограничения и постепенно формировать более здоровые цифровые привычки. История использования хранится на устройстве. Сбор начинается только после вашего согласия.

## Возможности

- **Экранное время:** статистика по приложениям за день, неделю, месяц или выбранный период.
- **Аналитика:** лента активности, тепловая карта, недельный отчёт и локальные подсказки.
- **Личные цели:** дневные лимиты для выбранных приложений и отслеживание прогресса.
- **Фокус:** фокус-сессии и локальная серия дней.
- **Темы:** несколько встроенных цветовых тем.
- **Управление данными:** экспорт и удаление локальных данных в Центре конфиденциальности.
- **Необязательный локальный ИИ:** подключение к Ollama на этом компьютере после отдельного согласия. REBOOT принимает только loopback-соединения.

REBOOT помогает следить за цифровыми привычками. Приложение не измеряет дофамин, не диагностирует зависимость и не даёт медицинских рекомендаций.

## Приватность

- Сбор статистики выключен до явного согласия.
- История использования и настройки хранятся локально.
- Само приложение не включается в статистику.
- Необязательный ИИ-помощник использует локальный сервер Ollama и включается отдельно.
- В Центре конфиденциальности можно проверить согласия, экспортировать или удалить локальные данные.

В уведомлении о конфиденциальности внутри приложения пока остались незаполненные данные оператора и контакта. Перед распространением сборки их нужно заполнить и сверить текст с фактической версией приложения.

## Сборка из исходников

Установите Flutter с версией Dart, удовлетворяющей ограничению в `pubspec.yaml`, затем выполните:

```sh
flutter pub get
```

Соберите приложение на соответствующей платформе:

```sh
# macOS (команду нужно запускать на macOS)
flutter build macos --release

# Windows (команду нужно запускать на Windows)
flutter build windows --release
```

Для запуска в режиме разработки:

```sh
flutter run -d macos
# или
flutter run -d windows
```
