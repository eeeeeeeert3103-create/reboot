# REBOOT для компьютера — зачем он людям

REBOOT показывает, куда уходит время за компьютером, помогает поставить себе ориентиры и мягкие ограничения. Всё хранится и считается на этом устройстве.

## Кому и в каких ситуациях

| Кто | Ситуация | Что в REBOOT помогает |
|---|---|---|
| Студент | Курсовая «пишется» весь день, а сделано мало | Лента дня показывает реальные переходы «редактор → браузер → мессенджер»; фокус-сессии 25/50 мин; мягкое ограничение на игры после лимита |
| Удалённый сотрудник | Рабочий день расползается на вечер | Heatmap и «самый активный час» показывают, во сколько на самом деле заканчивается работа; дневная цель и серия дней |
| Фрилансер | Нужно понять, сколько реально ушло на проект | Детали приложения: время, сессии, запуски по дням; экспорт недельного отчёта |
| Разработчик / дизайнер | Отвлечения ломают «поток» | Фокус-сессии с долей времени в рабочих приложениях; разрывы в ленте |
| Геймер | Хочет играть, но в разумных пределах | Цель для игры (например, 120 мин) + мягкое ограничение с «ещё 5 минут» |
| Родитель на общем компьютере (свой профиль ОС) | Хочет видеть собственные привычки, а не следить за другими | Данные только своей учётной записи; нет скрытого сбора и удалённой отправки |
| Человек после выгорания | Нужен мягкий самоконтроль без давления | Серия без штрафов, советы без оценок, локальный ИИ по желанию |
| Контент-мейкер | Монтаж vs. «просто смотрю видео» | Разбивка по приложениям и часам, сравнение недель |
| Школьник/студент перед экзаменами | Подготовка по расписанию | Фокус-сессии + еженедельный отчёт: сколько дней цель выполнена |

## Сценарии

1. **«Куда делся день?»** — открыть Ленту дня вечером: видно сессии, бездействие, блокировки и переходы между приложениями.
2. **«Меньше соцсетей/видео»** — поставить цель для браузера-развлечений или клиента видео, включить напоминание на 80 % и мягкое ограничение на 100 %.
3. **«Работа без отвлечений»** — фокус-сессия на 50 минут, отметить рабочие приложения; после — доля времени в них.
4. **«Нормальный вечер»** — по Heatmap видно, что активность после 22:00 высокая; цель «до 6 ч в день» и серия помогают держать ритм.
5. **«Неделя в цифрах»** — Отчёт: общее время, изменение к прошлой неделе, топ-5, самый активный день и час, фокус; экспорт файла.
6. **«Совет без облака»** — включить локального ИИ-помощника (Ollama на этом компьютере) и получить 3 совета по сводке недели.
7. **«Компьютер не мой — мои данные мои»** — экспорт и полное удаление в Центре приватности.

## Идеи развития (не реализовано)

- Расписания для ограничений (например, игры только после 19:00).
- Категории приложений, которые пользователь задаёт сам (работа / учёба / отдых).
- Цели «не меньше» (например, ≥ 2 ч в редакторе кода).
- Пауза-напоминания каждые N минут непрерывной работы (с согласия, без системных уведомлений по умолчанию).
- Синхронизация между своими устройствами — только сквозное шифрование и только с отдельного согласия; сейчас сети нет.
- Сводка дня в Menu Bar / трее с мини-графиком.
- Импорт/экспорт целей между компьютерами.
