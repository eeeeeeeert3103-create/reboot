REBOOT — версия @VERSION@ (сборка @BUILD@)
===========================================

REBOOT — приложение цифрового благополучия для macOS и Windows. Оно показывает,
сколько времени вы проводите за компьютером и в каких приложениях, помогает
задать дневную цель экранного времени и следить за серией дней (streak),
в которые цель соблюдалась.

REBOOT не измеряет дофамин, не диагностирует зависимость и не является
медицинским изделием. Цифры в приложении — это подсчёт времени по событиям
операционной системы, а не оценка здоровья.

Состав пакета
-------------
  README.txt               — этот файл
  VERSION.txt              — версия, дата сборки, статус подписи
  PRIVACY_POLICY.md        — политика конфиденциальности (черновик, см. ниже)
  THIRD_PARTY_NOTICES.txt  — лицензии сторонних компонентов (Flutter и др.)
  macOS:   REBOOT.app
  Windows: reboot_app.exe и файлы рядом с ним (DLL, папка data)

Важно про подпись
-----------------
Эта сборка может быть не подписана сертификатом разработчика (Apple Developer ID
на macOS, Authenticode на Windows). Точный статус указан в VERSION.txt, строка
«Code signing». Поэтому система при первом запуске покажет предупреждение.
Скачивайте пакет только из источника, который вам дал разработчик, и при
возможности сверяйте контрольную сумму SHA-256 (файл .sha256 рядом с архивом):
  macOS:   shasum -a 256 REBOOT-macOS-v@VERSION@.zip
  Windows: Get-FileHash -Algorithm SHA256 .\REBOOT-Windows-v@VERSION@.zip


=====================================================================
macOS
=====================================================================

Требования: macOS 12 Monterey или новее, Intel или Apple Silicon.

Установка и первый запуск
  1. Распакуйте архив двойным щелчком.
  2. Перетащите REBOOT.app в папку «Программы» (Applications).
  3. Если приложение не подписано Developer ID, macOS не даст открыть его
     двойным щелчком. Выберите один из способов:

     Способ А — через контекстное меню:
       • в Finder щёлкните REBOOT.app правой кнопкой (или Control + щелчок)
         и выберите «Открыть»;
       • в появившемся окне снова нажмите «Открыть».
       В новых версиях macOS (15 Sequoia и новее) кнопки «Открыть» в этом окне
       может не быть. Тогда закройте окно, откройте «Системные настройки» →
       «Конфиденциальность и безопасность», прокрутите вниз и нажмите
       «Всё равно открыть» напротив сообщения о REBOOT.

     Способ Б — снять карантин в Терминале:
         xattr -dr com.apple.quarantine /Applications/REBOOT.app
       Затем откройте приложение как обычно.

     Это нужно сделать один раз. Делайте это только для пакета, полученного
     от разработчика REBOOT.

Где хранятся данные (macOS)
  Приложение работает в sandbox-контейнере. Все данные лежат в папке
    ~/Library/Containers/com.reboot.app.rebootApp/
  В ней: usage-history/*.json (история использования), consent.json (согласие),
  streak.json (серия дней), feedback.json (отзывы), а также настройки
  приложения (UserDefaults).

Удаление (macOS)
  1. Если хотите стереть данные — в приложении откройте Privacy Center и
     нажмите «Удалить все локальные данные».
  2. Закройте REBOOT и перетащите REBOOT.app из «Программ» в Корзину.
  3. Удаление приложения может не удалить данные. Чтобы удалить всё вручную,
     удалите папку ~/Library/Containers/com.reboot.app.rebootApp/
     (в Finder: «Переход» → «Переход к папке…», вставьте путь).
  4. Файлы экспорта, которые вы сохраняли сами, удалите вручную.


=====================================================================
Windows
=====================================================================

Требования: Windows 10 или 11, 64-бит (x64). Права администратора не нужны.
Нужные библиотеки Visual C++ (msvcp140.dll, vcruntime140.dll,
vcruntime140_1.dll) уже лежат в пакете рядом с программой.

Установка и первый запуск
  1. Щёлкните архив правой кнопкой → «Извлечь все…» и распакуйте в удобную
     папку, например C:\Program Files\REBOOT или папку в своём профиле.
     Не запускайте программу прямо из архива: reboot_app.exe должен лежать
     вместе со всеми DLL и папкой data.
  2. Запустите reboot_app.exe.
  3. Если файлы не подписаны Authenticode, SmartScreen покажет окно
     «Система Windows защитила ваш компьютер». Нажмите «Подробнее», затем
     «Выполнить в любом случае». Это нужно сделать один раз.
     Делайте это только для пакета, полученного от разработчика REBOOT.
  4. Для удобства создайте ярлык: правой кнопкой по reboot_app.exe →
     «Показать дополнительные параметры» → «Создать ярлык».

Где хранятся данные (Windows)
    %LOCALAPPDATA%\REBOOT\   (обычно C:\Users\<имя>\AppData\Local\REBOOT\)
  В ней: usage-history\*.json, consent.json, streak.json, feedback.json,
  settings.json (настройки). Файлы экспорта сохраняются в Documents\REBOOT.

Удаление (Windows)
  1. Если хотите стереть данные — в приложении откройте Privacy Center и
     нажмите «Удалить все локальные данные».
  2. Закройте REBOOT и удалите папку, куда вы распаковали пакет.
     Установщика нет, поэтому в «Установленных приложениях» REBOOT не
     появляется и записей в реестре не создаёт.
  3. Чтобы удалить всё вручную, удалите папку %LOCALAPPDATA%\REBOOT\ и при
     необходимости Documents\REBOOT\ (файлы экспорта).


=====================================================================
Что собирает REBOOT (кратко; подробно — в PRIVACY_POLICY.md)
=====================================================================

Режимы
  • DEMO — показываются примерные данные, статистика компьютера не собирается.
  • REAL — сбор начинается только после вашего явного согласия в приложении
    и идёт только пока REBOOT запущен. Фоновой службы нет.

В режиме REAL сохраняется
  • какое приложение активно (macOS — bundle ID и имя; Windows — имя exe и
    описание файла, без полного пути);
  • отрезки активного использования (начало, конец, длительность);
  • запуски приложений;
  • периоды бездействия (нет ввода 120 секунд и дольше) — читается только
    время последнего ввода, какие клавиши нажаты, не узнаётся;
  • время блокировки/разблокировки экрана и сна;
  • интервалы, когда сбор действительно шёл.
  Также сохраняются ваши настройки, отметка о согласии, серия дней и отзывы.

REBOOT НЕ собирает
  заголовки окон, адреса сайтов, названия и содержимое документов, переписку,
  нажатия клавиш и вводимый текст, пароли, снимки экрана, звук и камеру,
  местоположение, контакты, рекламные идентификаторы.

Передача данных
  REBOOT никуда не отправляет ваши данные: нет серверов, аналитики, рекламы,
  отчётов о сбоях и ИИ-сервисов. Данные покидают компьютер, только если вы
  сами экспортируете их (Privacy Center → экспорт в JSON) и куда-то отправите.
  Файлы данных и экспорта хранятся в формате JSON и отдельно не шифруются.

Сроки хранения
  История использования хранится 90 дней и затем удаляется автоматически.
  Согласие, настройки, серия дней и отзывы хранятся, пока вы их не удалите.
  Отозвать согласие можно в любой момент в Privacy Center.

PRIVACY_POLICY.md — черновик политики, который ещё проходит юридическую
проверку; места с пометкой [НЕ УКАЗАНО: …] будут заполнены до публичного
выпуска.

Лицензии сторонних компонентов — в THIRD_PARTY_NOTICES.txt.
